

# Sakai-Aufgabe: Objektorientierung

Dieses Projekt analysiert EKG-Daten und erkennt Peaks automatisch.

## Funktionen
- Einlesen von EKG-Daten
- Peak Detection mit Glättung und Schwellenwert
- Berechnung der durchschnittlichen Herzfrequenz
- Visualisierung mit Plotly

![EKG-Peaks](Screenshot_Objektorientierung)

## Nutzung
Virtuelle Umgebung und Abhängigkeiten installieren

    pdm install
Streamlit-App starten

    pdm run streamlit run main.py
